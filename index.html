Сохраняем проект и делаем бэкап

Одна рабочая папка. Одна резервная копия.

  1. Откройте основную папку проекта в Cursor.
  2. Выберите File → Save All — «Файл → Сохранить всё».
  3. Откройте расположение проекта в Проводнике Windows. Выделите папку проекта и нажмите Ctrl + C, затем Ctrl + V в её родительской папке.
  4. К названию получившейся копии добавьте -backup. Работайте дальше в исходной папке.
Backup — «бэ́кап». Это резервная копия состояния проекта перед подготовкой. Название исходной папки может быть вашим; к названию её копии добавьте -backup.
Реплика спикера

Сначала сохраняем все изменения. Затем копируем папку проекта и добавляем к названию копии слово «бэкап». Эта копия сохранит состояние сайта перед подготовкой. Её оставим без изменений, а работать продолжим в основной папке.

Зачем отдельная папка

В публичный репозиторий попадает только подготовленный комплект.

Рабочая папка

Здесь могут быть черновики, личные материалы, резервные файлы и настройки. Продолжаем разработку в ней.

Папка upload

Здесь лежат проверенные файлы сайта, которые мы выбрали для загрузки. Это комплект для переноса.

Пароли, секретные API-ключи и токены доступа никогда не должны попасть в чужие руки или публичный репозиторий. Они могут давать доступ к сервисам, данным и платным ресурсам. Проверка ИИ помогает, но перед загрузкой мы сами просматриваем список файлов.

Публичное имя, рабочая почта, Telegram и фотографии для сайта — часть портфолио. Секретные данные для авторизации сервисов — другая категория.

Удаление секрета из текущего файла не гарантирует его исчезновения из истории коммитов. Если секрет уже опубликован, его нужно отозвать или заменить у провайдера и обратиться к куратору.

Реплика спикера

Сайт — это не только страница в браузере. За ней стоят файлы, а в рабочей папке могут лежать материалы, которые не должны попасть в публичный репозиторий. Особенно проверяем пароли, секретные ключи и токены. После проверки Cursor мы тоже смотрим, что отправляем.

Частые вопросы

Нужно ли копировать сам файл этого гайда в проект?

Нет. Гайд — инструкция. В репозиторий сайта загружаются файлы вашего сайта.

Можно ли перенести всю рабочую папку?

Для этого урока используйте проверенный комплект upload. В рабочей папке могут оставаться непубличные файлы.

Почему нельзя надеяться только на .gitignore?

Это правило для работы Git. При ручной загрузке через браузер сами выбирайте безопасные файлы: не считайте наличие .gitignore фильтром для выбранных вами файлов.

Cursor не может заполнить соседнюю папку

Проверьте полный путь. Если Cursor запросил доступ к конкретной папке upload, предоставьте доступ к ней. Не разрешайте ему вместо этого менять исходный проект.

Файлы уже загрузились — сайт опубликован?

Нет. В этом уроке мы сохраняем проект в репозитории. Размещение сайта — отдельная настройка.
